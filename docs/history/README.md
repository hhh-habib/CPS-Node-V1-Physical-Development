# Historical physical evidence

The documents here describe an **earlier pre-nRF SG90 + HC-SR04 revision**, not the current fixed environmental Stage 5A node.

[Pre-nRF functional validation](PRE_NRF_NODE_V1_FUNCTIONAL_VALIDATION.md) preserves the original qualitative observations, indoor test distances, duration and directional-command results. These are historical owner-reported conditions, not current RF range, latency, reliability or calibration specifications. The original session date is not established by this synchronization.

For current evidence use [Stage 5A physical validation](../STAGE5A_PHYSICAL_VALIDATION.md). For current pins use [hardware architecture](../HARDWARE_ARCHITECTURE.md). The obsolete API and software/paper audit are preserved in Git history rather than maintained as duplicate files.
